# 10-minute timed comparison (optional, for the Impact section)

Use only if the same participant (or another prospective volunteer) agrees. Nothing here has been run yet; don't report
results until a real session happens.

**Task (read aloud):** "Find one animal-volunteering role in Greater New Haven that you could do, and write down its minimum
age, its time commitment, and your next step to apply."

| Step | What the participant uses | Limit |
|---|---|---|
| A | An ordinary web search and the organizations' own websites (no app) | stop at 5 minutes |
| B | Animal Volunteer Finder (Explore, a detail page, or Find my fit) | stop at 5 minutes |

- **Order effect:** whichever goes second benefits from the first. With one person this can't be removed; record the order
  (ideally app first, so the manual search isn't helped by the app).
- **For each step, record:**
  - time to a written answer, or "not done at 5 min";
  - whether the minimum age and time commitment they wrote are correct (check them against `data/opportunities.json`);
  - one sentence they say about it, quoted with their permission.

| B app | | | | | |

Report it as "one participant, one task, order X: manual N s vs app M s". It is not a general time saving.
